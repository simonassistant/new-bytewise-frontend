## Coordination Strategy

### With Active Development
- Minimal interference approach
- Focus on user-facing documentation first
- Avoid documenting rapidly changing technical details
- Coordinate through documentation updates rather than code changes

### Documentation Principles
1. **Brief but informative** - Essential information without overwhelming detail
2. **User-focused** - Prioritize end-user needs over technical specifications
3. **Maintainable** - Easy to update as the project evolves
4. **Collaborative** - Open to input from Kaitai and other contributors
