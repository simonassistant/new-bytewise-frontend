# Writing Bot Documentation

This folder contains documentation and comments for the Writing Bot component of the new-bytewise-frontend application.

## Overview

The Writing Bot is an AI-powered writing assistant designed to help students improve their essay writing through interactive feedback and revision guidance.

## Folder Structure

- `README.md` - This overview document
- `component-analysis.md` - Detailed analysis of the WritingBot component
- `api-documentation.md` - API endpoints and integration details
- `user-guide.md` - User guide for the Writing Bot features
- `development-notes.md` - Development notes and comments

## Key Features

- **Three Modes**: Briefing, Training, and Assessment
- **Interactive Chat**: Real-time conversation with AI assistant
- **Progress Tracking**: Monitor exchanges, questions, and revisions
- **Draft Comparison**: Compare original and final drafts
- **Export Functionality**: Save chat history for review

## Deployment

The Writing Bot is deployed at: https://textbot.hkbu.tech/writingBot
