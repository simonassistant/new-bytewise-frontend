# 🚀 Quick Start Guide - Poe Chat GUI

## Get Started in 3 Steps

### 1. Install Dependencies
```bash
pip install -r requirements_gui.txt
```

### 2. Start the GUI
```bash
python start_gui.py
```

### 3. Open Your Browser
Go to: http://localhost:5000

## Quick Tips

- **Start with F1 Preview** for testing (only 1 point!)
- **Use GPT-3.5 Turbo** for most conversations
- **Switch to GPT-4o** for complex analysis
- **Save your chats** - Click "💾 Save Chat" to save conversations
- **Start new chats** - Click "➕ New Chat" to begin fresh conversations
- **Check your balance** - you have 1,110,508 points available!

## Troubleshooting

**Server won't start?**
- Check if port 5000 is free
- Run `python test_gui_setup.py` to diagnose

**API errors?**
- Verify your Poe API key is working
- Check your internet connection

**Need help?**
- Read the full `README_GUI.md` for detailed instructions
- Check the server console for error messages
